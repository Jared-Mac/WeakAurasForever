# WeakAurasForever logo

Original WAF lettering surrounded by an infinity-shaped aura, in teal, gold,
and ivory on a dark navy background. Created for this fork with the built-in
image_gen tool on 2026-09-23; no reference image or upstream logo was used.
Distributed with the project under GPLv2 (see ../../LICENSE).

- waf-logo-source.png: unchanged generated master.
- waf-logo-400.png: 400 x 400 PNG for the CurseForge project avatar.
- ../../WeakAuras/Media/Textures/WAF.tga: 256 x 256 uncompressed TGA for WoW.

The smaller files are mechanical size/format exports of the master, with no
changes to the artwork. They are used by the README and Forever addon branding.

## Generation prompt

Use case: logo-brand. Create a single original, polished logo/avatar for WeakAurasForever, a customizable fantasy MMO interface addon, abbreviated WAF. Square 1:1 finished image for a CurseForge project avatar, ideally exactly 400 by 400 pixels, crisp enough to also serve as the source for larger exports if necessary. Deep near-black navy background filling the square. One bold, clean, original emblem: an angular luminous aura loop suggesting infinity, framing the clearly legible custom geometric letters WAF. Teal/cyan light with restrained warm gold accent, bright ivory letterforms. Restrained fantasy feel through the aura shape, otherwise modern graphic design with simple strong silhouettes, generous breathing room, excellent legibility at 48 pixels. Flat vector-like finish, only subtle controlled gradients; no ornate filigree, no 3D mockup, no scenery, no characters. Exact text: WAF. Do not include any other text. Completely original graphic: do not use or resemble the WeakAuras WA logo, Blizzard or Warcraft logos, or any game art. Deliver one centered finished avatar, not a contact sheet, on opaque dark background.
